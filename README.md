## Projects

### Employee Attrition Segmentation

Used K-Means clustering on IBM HR data to group employees into distinct segments. Picked the cluster count using elbow and silhouette methods, then built a five-tab Dash app to explore the results.

Python · scikit-learn · pandas · Dash

[![View App](https://img.shields.io/badge/View_App-1a1a2e?style=for-the-badge)](https://proves-tomato-loon-d6728cdc.plotly.app/)

### NYC Airbnb Price Analysis

Built a regression model to find what actually drives nightly listing price. Encoded borough and room type, then interpreted the coefficients to show which features move price and by how much.

Python · pandas · scikit-learn · Plotly

### Automotive Recall & Complaint Analysis (in progress)

Team project using NHTSA complaint and recall data to support parts-stocking decisions. Sorting free-text component names into part categories and flagging which vehicles had recalls.

Python · pandas · Google Colab
